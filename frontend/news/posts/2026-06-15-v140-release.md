# v1.4.0 - Ammo Ballistics Table & Optimizations

**Released:** 2026-06-15

v1.4.0 introduces the Ammo Ballistics Table, a new section of the site dedicated to browsing and comparing ammunition statistics across all calibers. Alongside it come a performance improvement to build loading, a UI sizing fix for the attachment grid, and overall experience optimizations.

---

## New: Ammo Ballistics Table

A dedicated ammo ballistics stats reference table is now available from the navigation bar.

![The ballistics table](./news/images/v140/ballisticsTable.webp "The ballistics table")

- **Full stat coverage** - Damage, penetration, armor damage, velocity, recoil modifier, fragmentation chance, and ricochet chance are all shown in a single table.
- **Caliber grouping** - Ammo is organized by caliber type, making it easy to compare rounds within the same category.
- **Tracker integration** - The table integrates with the existing stat tracker. Changes to ammo stats between game patches are tracked & highlighted.

---

## Performance: Faster Build Reconstruction

Build reconstruction (the process of restoring or loading a saved build(local, community, or external deep-link) in the modding interface) is significantly faster.

- Slot and allowed-item caches are now pre-warmed in a single batch at the start of reconstruction, eliminating repeated cache misses for complex builds with many attachments.

![Build reconstruction behind-the-scenes, before & after](./news/images/v140/buildReconstructCompare.webp "Build reconstruction behind-the-scenes, before & after")

---

## UI Improvements

- **Left panel width** - The minimum width of the left panel in the builder has been increased to 660px, giving the attachment grid more room on wider displays.
- **Attachment grid cells** - Grid cells in the attachment grid view are scaled up slightly for better readability.

---

## Bug Fixes

- **Language selector on mobile** - The language selector dropdown was incorrectly cut-off on mobile viewports. It is now freed && anchored correctly.

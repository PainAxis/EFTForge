# v1.3.4 - Mobile Compatibility Optimizations Iteration 2

**Released:** 2026-05-27

v1.3.4 is the second round of mobile-focused improvements. The attachment table drawer has been significantly reworked, the attachment table itself is now fully usable on a phone screen, and a handful of smaller polish items have been addressed across both mobile and desktop.

---

## Attachment Table Drawer Rework

The slide-up drawer that hosts the attachment selection table has been rebuilt from the ground up for a more native-feeling experience.

- **Swipe down to close** - Drag the handle bar at the top of the drawer downward to dismiss it. The panel follows your finger and snaps back if you release short of the threshold, or closes if you cross it. Tapping anywhere on the dimmed backdrop also closes the drawer.
- **Drawer height** - The drawer now opens to 75% of the screen height instead of nearly full-screen, so more of the dimmed build view remains visible behind it, making the context of what you are modding more obvious.
- **Back to Build button removed** - The button inside the drawer has been removed. The swipe-down gesture and backdrop tap replaces it.

---

## Attachment Table Overhaul

The attachment table has been completely reworked for portrait mobile use.

- **Horizontal scroll** - The table now scrolls horizontally, giving every stat column room to breathe. Swipe right to reveal price, weight, recoil, accuracy, and ergo without any columns being permanently cut off.
- **Sticky column headers** - The header row sticks to the top of the drawer as you scroll down through a long attachment list so you always know which column is which.
- **All stat columns restored** - Accuracy and ergonomics columns are no longer hidden on mobile. Column autohide still works as on desktop - if none of the attachments in a slot carry a particular stat, that column disappears.
- **Swipe-to-remove disabled in table** - The swipe-left-to-remove gesture no longer fires on attachment table rows on mobile. Horizontal swiping is now reserved for scrolling to see stats. Removal is still available via swipe-left on slots in the Workbench panel.
- **Short name badges hidden** - The small slot-name chip on attachment icons in the table is hidden on mobile to reduce visual clutter.
- **Combo icon row** - The combination preview icon strip in combo view is now touch-scrollable so you can swipe through all icons in the combination.
- **Combo name column width** - The name cell in combo view is given a minimum width of 300px so long combination names are readable.

---

## Mobile UI Polish

Several smaller adjustments across the mobile layout.

- **Header** - The "EFTForge" site name is hidden on mobile portrait; only the logo mark is shown to preserve header space.
- **Build control buttons** - Button labels in the builder toolbar are shortened on mobile (Back, Reset, Strip, Save, Explore) so they never wrap to a second line.
- **Modals** - All modal windows are now capped at screen width minus a safe margin and scroll internally, preventing any modal from overflowing on portrait orientation.
- **Publish button** - The Publish button in the saved builds modal is hidden on mobile. The publish hint text updates to note that publishing from a mobile device is not supported.
- **Grid/List view toggle** - The grid and list view toggle buttons in the workbench toolbar are hidden on mobile since grid view is not available in the single-column layout.
- **Toast notifications** - Toasts return to their compact size and bottom-right position instead of stretching full-width across the screen.

---

## Desktop Improvement

- **Favorite stars always visible** - The star button on each attachment table row is now visible at all times instead of only appearing on row hover. Unfavorited rows show the star in a dim state; favorited rows show it in gold.
